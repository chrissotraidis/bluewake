# BlueWake performance

This documentation explains how BlueWake performance is measured, how a
bottleneck is assigned to a runtime component, and how a proposed optimization
is compared without losing correctness.

Start with the [performance overview](Overview.md). It connects the measurement
workflow to the [architecture documentation](../architecture/README.md) and
points to the existing profiling, benchmarking, and optimization references.

For native game-thread worker changes, continue to the
[game-thread qualification runbook](GameThreadQualification.md).
